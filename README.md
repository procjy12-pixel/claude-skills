# 클로드 스킬 두 개 · 카드뉴스 · 블로그 원고

강의 「여러분은 지금 AI를 잘못 쓰고 계십니다 · 파트 2」에서 나눠 드리는 스킬입니다.

| 폴더 | 하는 일 |
|---|---|
| `card-news` | 주제 한 줄 → 인스타 카드뉴스 7장과 캡션. 브라우저에서 PNG로 저장 |
| `blog-writer` | 주제 한 줄 → 네이버 블로그 원고와 붙여 넣기용 미리보기 |

## 설치 · 한 줄

클로드 앱 → 코드에서 아무 폴더나 고르고 이렇게 치세요.

```
github.com/procjy12-pixel/claude-skills 에 있는 스킬 두 개 내 컴퓨터에 설치해줘
```

설치가 끝나면 새 대화를 여세요.

## 직접 설치

1. 이 페이지의 초록색 Code 버튼 → Download ZIP
2. 압축을 풀고 `card-news`, `blog-writer` 두 폴더를 옮깁니다
   - 맥: 홈 폴더의 `.claude/skills` 안
   - 윈도우: `C:\Users\내이름\.claude\skills` 안
3. 클로드 앱에서 새 대화

## 쓰는 법

- `카드뉴스 만들어줘. 주제: ○○` → 카드뉴스.html 을 열고 [PNG로 전부 저장]
- `블로그 글 써줘. 주제: ○○` → 쓰는 사람·말투 번호 두 개 고르기 → [본문 복사] 해서 네이버 글쓰기에 붙여 넣기

회사 이름·색·단가 같은 자료가 폴더에 있으면 읽어서 씁니다. 근거 없는 숫자나 후기는 지어내지 않습니다.
네이버 블로그는 프로그램으로 글을 올리는 것을 약관으로 제한하므로, 원고는 복사해서 직접 붙여 넣으세요.
